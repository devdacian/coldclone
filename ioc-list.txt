# confirmed-malicious package identifiers (typosquats, supply-chain compromises,
# DPRK/Lazarus drops, infostealer campaigns), not malware-family labels.
#
# Format: a plain package name is a package-wide trigger: all versions of that
# identity are known malicious (for example, a typosquat). Exact malicious
# releases of an otherwise legitimate package use:
# VERSION: <ecosystem> | <package-name> | <exact-version>
# Once VERSION records exist, trusted exact versions not listed are treated as
# safe. OSV exact-version queries opportunistically supplement this static set.
# Legacy provenance finalizers may remain in synchronized source data:
# AFFECTED_SET_COMPLETE: <ecosystem> | <package-name>
# VERSION ecosystems are limited to npm and crates.io, where the scanner has
# trusted exact extractors. Finalizers are validated but do not affect matching;
# VERSION records themselves are the exact denylist. Malformed structured
# records make the policy invalid and fail the scan closed.
# Example (commented and therefore inert):
# VERSION: npm | keyv | 6.0.0
# Lines starting with `#` are comments and preserve source attribution. Empty
# lines are allowed for readability.
